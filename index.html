Send it for approval

Each document goes to the project manager first, then to the HOD, and the HOD’s signature is placed by their PA. They travel separately, so each one has its own status — follow them on the next step.

Which documents go?

Not connected to the database. A claim travels between five people on five machines, so it needs the shared database — which this browser cannot reach right now. Nothing is lost: the form is still saved here, and the documents still download.

Status

Where every claim has got to, and what is waiting on you.

Signed copies on file

When a document comes back signed, upload it here. Copies are kept against the person and the month, so any month can be produced again later without hunting through anybody’s downloads.

History

Every signed copy ever filed, for everybody, newest first. The Status step shows one month; this is the whole record, which is what Finance asks for when they ask about last March.
